LangChain is a framework for building applications powered by large language models (LLMs). It provides tools and abstractions to simplify the development of complex AI workflows, from simple chatbots to complex agent systems.

A chat model is an LLM optimized for conversational interactions. Unlike general-purpose LLMs, chat models accept message role assignments (system, user, assistant) and maintain conversation context, making them ideal for dialogue systems like the WhatsApp chatbot.

A prompt template is a reusable prompt structure with placeholders that can be filled at runtime. It enables consistent prompt formatting across multiple LLM calls, supports variable injection (e.g., user message, conversation history), and promotes prompt versioning and reuse.

Document loaders are utilities that read and parse external data sources (files, websites, databases) into a uniform Document format containing page content and metadata. They are the first step in R pipelines, transforming raw data into structured pieces the system can process.

Text splitting breaks long documents into smaller, overlapping chunks while preserving context. This is necessary because LLMs have token limits; splitting ensures content fits within model constraints while maintaining semantic coherence across chunks.

Embeddings are vector representations of text that capture semantic meaning. Generated by embedding models, similar texts have similar vector distances. Embeddings enable mathematical comparison of text content, forming the basis for similarity search in RAG systems.

A vector store is a database specialized for storing and querying embeddings. It supports efficient similarity search (finding the closest vectors to a query vector) and CRUD operations. Examples include Pinecone, Weaviate, Chroma, and Qdrant, enabling scalable similarity-based retrieval.

A retriever fetches the most relevant documents or chunks given a query. It typically uses a vector store to compute embeddings for the query and returns the nearest neighbors based on cosine similarity or other distance metrics, providing context for generation.

Retrieval-Augmented Generation (RAG) combines retrieval and generation: the retriever fetches relevant documents from a knowledge base, and the LLM incorporates that context when generating its response. This allows the model to answer using external knowledge without retraining.

A chain is a sequence of computational steps (LCC) where the output of one step becomes the input of the next. In LangChain, chains connect components like prompt templates, LLMs, and retrievers into workflows, enabling complex logic with minimal code.

An agent is an LLM-driven decision-maker that can select and execute actions dynamically. The agent observes its environment, reasons about which tool or chain to use, and continues until a stop condition is met. Agents power autonomous systems that can interact with external APIs, databases, and tools.
